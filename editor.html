項目数・節番号・検索インデックスはビルド時に自動計算されます。

使い方

  1. npm run dev で起動
  2. フォームを編集
  3. 「保存してビルド」を押す
  4. サイトを再読込

JSONを直接編集したい場合は「JSON」タブへ。書き出したファイルは content/ に上書きしてください。

content/article.json

基本情報

記事タイトル、概要、ヒーロー画像、パンくず、リンク語句などを編集します。

タイトルと概要

article.json

ヒーロー画像

article.json / hero
プレビュー

このサイトについて

article.json / about

パンくずリスト

記事名は自動で末尾に付きます。ここには上位階層だけを並べます。

記事ヘッダーのリンク

タイトル下に縦に並ぶリンクです。primary を付けたものが太字になります。

本文のリンク語句

本文中の [[語句]] を、ここに登録したURLへリンクします。語句は完全一致です。

編集履歴

記事の「編集履歴」ダイアログに表示されます。新しい順に並べてください。

content/article.json / sections

本文

節を追加・並べ替え・削除し、それぞれのブロックを編集します。節番号はビルド時に自動で振られます。

関連タグ

article.json / relatedTags

カテゴリ

記事末尾のカテゴリ一覧と、サイドバーのカテゴリカードを編集します。項目数は自動計算されます。

categories.json

ヘッダー

注目リンク

query を入れると検索、href を入れるとページ内リンクになります。

フッター

モバイルメニュー

raw JSON

JSON

3つのJSONを直接確認・編集できます。反映したあと「保存してビルド」を押してください。

JSONエディタ

site.json

「エディタに反映」は構文チェックだけ行い、保存はしません。保存前に内容を確認してください。

ファイルから読み込む

content/ のJSONを選択するとエディタに読み込みます。3ファイルをまとめて選択できます。

静的ホスティングの場合

このエディタの保存機能はローカルサーバー（npm run dev）専用です。 静的ホスティングでは「書き出し」でJSONをダウンロードし、リポジトリの content/ に上書きしてから npm run build を実行してください。
