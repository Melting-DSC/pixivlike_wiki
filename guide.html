SITE GUIDE

使い方

記事ページを開いたまま編集モードへ切り替え、タイトル・本文・画像を書き換えられます。 変更はこのブラウザに自動保存され、記事に戻るとすぐに反映されます。

クイックスタート

記事ページをブラウザで開き、ヘッダー右上の「この記事を編集」を押します。 ページの移動はなく、記事の上に編集モードが重なって開きます。

記事ページindex.html 編集モードindex.html#editor
  1. 編集モードを開くヘッダーの「この記事を編集」、サイドバーやメニューの「編集モードを開く」から開けます。
  2. フォームで書き換える左のメニューから基本情報・本文を選びます。
  3. 記事に戻る「記事に戻る」を押すと、編集した内容がそのまま記事に反映されています。
保存のたびにボタンを押す必要はありません。

入力は自動でこのブラウザに保存されます。明示的に保存したいときは「今すぐ保存」を押してください。

編集モードの使い方

編集モードは記事ページの中にあります。ページを移動しないため、編集中の内容が消える心配はありません。 左側のメニューで編集する場所を切り替えます。

基本情報

タイトル、読み、概要、ヒーロー画像、パンくず、ヘッダーリンク、リンク語句、編集履歴。

本文

節とブロックの追加・削除・並べ替え。段落、リスト、コード、注記、画像、タグ、引用、区切り線。

書き出し

JSON・HTML・PNG・PDFへの書き出しと、JSONファイルの読み込み。

できること

  • 本文セクションとブロックの追加・削除・並べ替え。
  • Ctrl / Cmd + S で明示的に保存。
  • 「記事に戻る」で編集モードを閉じ、元の位置に戻る。
保存先はこのブラウザだけです。

編集内容はサーバーへ送信されません。別の端末やブラウザ、シークレットウィンドウには引き継がれません。 大切な内容は「書き出し」でJSONを保存しておいてください。

インライン記法

段落、リスト、注記、引用、キャプションでは、次の記法が使えます。

書き方結果
[[C++]]登録済みのリンク語句を使って「C++」をリンク。
[[C++|Cプラプラ]]表示名だけ変えてリンク。
[ラベル](https://example.com)通常のリンク。外部URLは新しいタブで開きます。
**強調**太字。
`コード`インラインコード。
[[語句]] のリンク先

「基本情報」の「本文のリンク語句」にURLや #アンカー を登録します。 未登録の語句は平文で表示されます。

HTMLタグはエスケープされ、そのままでは埋め込まれません。コードブロック内の code も そのまま表示されるため、インライン記法は適用されません。

画像

ヒーロー画像と本文中の画像は、編集モードの「画像をアップロード」から選択できます。 選択した画像はその場で記事に表示され、書き出しにも含まれます。

  • アップロードした画像はこのブラウザに保存されません。
  • ページを開き直したときは、画像を選び直してください。未設定の画像は「画像未設定」と表示されます。
  • 画像パスに assets/images/ファイル名 や https:// のURLを直接入力することもできます。
  • 画像には内容を説明する代替テキスト（alt）を付け、出典がある場合はクレジットに記載してください。
画像は毎回選び直します。

データを軽く保つため、アップロード画像そのものは保存対象外です。 同じ画像を使い続けたい場合は、画像パスに固定のURLやリポジトリ内のパスを指定してください。

書き出し

編集モード左側の「書き出し」から、記事を4つの形式で保存できます。 用途に合わせて選んでください。

形式内容向いている用途
JSON サイト・記事を1つのファイルにまとめたもの。 バックアップ、再編集、別のブラウザへの移行。
HTML CSSと画像を埋め込んだ単体のHTMLファイル。 そのまま配布、静的ホスティングへの配置。
PNG 記事全体を1枚の画像にしたもの。 SNS、資料、画像としての共有。
PDF 記事全体をA4サイズの複数ページに分割したもの。 印刷、添付資料、閲覧用の配布。

書き出し中はボタンが一時的に使えなくなります。画像が多い記事は処理に少し時間がかかります。 PNGとPDFは記事全体を画像として描画するため、長い記事ではファイルサイズが大きくなります。

JSONがいちばん確実です。

あとから編集を続けたい場合はJSONを保存してください。HTML・PNG・PDFは閲覧・配布用で、再編集には使えません。

読み込み

「書き出し」パネルの「ファイルから読み込む」から、JSONを選んで編集を再開できます。

  • このサイトが書き出したJSON（サイト・記事をまとめたもの）をそのまま選べます。
  • site.json、article.json の2ファイルをまとめて選ぶこともできます。
  • 読み込んだ内容は、その場で記事に反映され、このブラウザに保存されます。
  • 読み込み前に現在の編集内容を残したい場合は、先にJSONを書き出してください。

注意事項

  • 編集内容はこのブラウザの localStorage に保存されます。ブラウザのデータを消去すると編集内容も消えます。
  • アップロードした画像は保存されません。開くたびに再選択してください。
  • 別の端末やブラウザへ移す場合は、JSONを書き出して読み込み直してください。
  • 大きな変更の前には、JSONの書き出しでバックアップを取ってください。
  • このサイトは「ピクシブ百科事典」の外観を参考にした非公式パロディです。実在の記事・画像・ロゴとは関係ありません。
  • 検索避けのため、全HTMLページに noindex を指定し、robots.txt でクロールを拒否しています。GitHub Pages は公開状態のままなので、アクセス制限ではありません。
