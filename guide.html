クイックスタート

記事ページをブラウザで開き、ヘッダー右上の「この記事を編集」を押します。 ページの移動はなく、記事の上に編集モードが重なって開きます。

記事ページ記事を読む 編集モード記事を書き換える
  1. 編集モードを開くヘッダーの「この記事を編集」や、サイドバーの「編集モードを開く」から開けます。
  2. フォームで書き換える左のメニューから基本情報・本文を選びます。
  3. 記事に戻る「記事に戻る」を押すと、編集した内容がそのまま記事に反映されています。
保存のたびにボタンを押す必要はありません。

入力は自動でこのブラウザに保存されます。明示的に保存したいときは「今すぐ保存」を押してください。

編集モードの使い方

編集モードは記事ページの中にあります。ページを移動しないため、編集中の内容が消える心配はありません。 左側のメニューで編集する場所を切り替えます。

基本情報

タイトル、読み仮名、概要、メイン画像、タイトル下のリンク。

本文

セクションとブロック（段落・リスト）の追加・削除・並べ替え。

書き出し/インポート

JSON・HTML・PNG・PDFへの書き出しと、JSONファイルのインポート。

できること

  • セクション（見出しとその内容）とブロック（段落・リスト）の追加・削除・並べ替え。
  • Ctrl / Cmd + S で明示的に保存。
  • 「記事に戻る」で編集モードを閉じ、元の位置に戻る。
保存先はこのブラウザだけです。

編集内容はサーバーへ送信されません。別の端末やブラウザ、シークレットウィンドウには引き継がれません。 大切な内容は「書き出し/インポート」からJSONファイルを書き出して保管しておいてください。

文字の装飾とリンク

概要・段落・リストの文章では、記号で囲むと文字を装飾できます。

書き方結果
**太字**太字になります。
[表示する文字](https://example.com)リンクになります。押すと新しいタブで開きます。
[[会社員]]リンクと同じ青い文字で表示します（押しても移動しません）。

画像

メイン画像は、編集モードの「基本情報」にある「画像をアップロード」から選択できます。 選択した画像はその場で記事に表示され、書き出しにも含まれます。

  • アップロードした画像は編集内容と一緒にこのブラウザに保存され、ページを開き直してもそのまま表示されます。
  • 画像が設定されていない場合は「画像未設定」と表示されます。
  • ネット上の画像を使う場合は、「画像のURL」に https:// で始まるURLを入力することもできます。
  • 「画像の説明」には画像の内容を書き、ほかの人が描いた画像を使う場合は「作者・出典」も記入してください。
保存されるのはこのブラウザだけです。

別の端末やブラウザでは画像も表示されません。移すときは、JSONファイルを書き出して読み込んでください（画像もJSONファイルに含まれます）。 ごく一部の古いブラウザやプライベートモードでは画像を保存できず、開くたびに選び直しが必要になることがあります。

書き出し

編集モード左側の「書き出し/インポート」から、記事を4つの形式で保存できます。 用途に合わせて選んでください。

形式内容向いている用途
JSON 編集内容をまるごと保存したファイル。 バックアップ、再編集、別のブラウザへの移行。
HTML 画像も含めた、ブラウザで開ける1つのWebページ。 そのまま人に渡す、Webに公開する。
PNG 記事全体を1枚の画像にしたもの。 SNS、資料、画像としての共有。
PDF 記事全体をA4サイズの複数ページに分割したもの。 印刷、添付資料、閲覧用の配布。

書き出し中はボタンが一時的に使えなくなります。画像が多い記事は処理に少し時間がかかります。 PNGとPDFは記事全体を画像として描画するため、長い記事ではファイルサイズが大きくなります。

JSONがいちばん確実です。

あとから編集を続けたい場合はJSONを保存してください。HTML・PNG・PDFは閲覧・配布用で、再編集には使えません。

インポート

「書き出し/インポート」パネルの「ファイルから読み込む」から、書き出しておいたJSONファイルを選ぶと編集を再開できます。

  • このサイトで書き出したJSONファイルをそのまま選べます。
  • 読み込んだ内容は、その場で記事に反映され、このブラウザに保存されます。
  • 読み込み前に現在の編集内容を残したい場合は、先にJSONを書き出してください。

注意事項

  • 編集内容はこのブラウザに保存されます。ブラウザの履歴やサイトデータを消去すると編集内容も消えます。
  • アップロードした画像もこのブラウザに保存されます。大きな画像をたくさん使うと、保存できる容量を超えることがあります。
  • 別の端末やブラウザへ移す場合は、JSONを書き出して読み込み直してください。
  • 大きな変更の前には、JSONの書き出しでバックアップを取ってください。
  • このサイトは「ピクシブ百科事典」の外観を参考にした非公式パロディです。実在の記事・画像・ロゴとは関係ありません。
  • このサイトは検索エンジンに載らないように設定していますが、URLを知っている人は誰でも見られます。
