export / import

書き出し/インポート

編集した記事をファイルとして保存したり、保存したJSONを読み込んだりします。JSONは再編集用、HTML・PNG・PDFは配布や閲覧用です。

書き出し形式

JSON

編集内容をまるごと保存するファイルです。あとから「ファイルから読み込む」で編集を再開できます。バックアップにも使えます。

HTML

ブラウザで開ける1つのWebページとして保存します。画像も含まれるので、そのまま人に渡したり、Webに公開したりできます。

PNG

記事全体を1枚の画像として保存します。SNSや資料への貼り付けに向いています。

PDF

記事全体をA4サイズの複数ページに分割して保存します。印刷や配布用です。

書き出し中はボタンが一時的に使えなくなります。画像が多い記事は少し時間がかかります。

ファイルから読み込む

このサイトで書き出したJSONファイルを選ぶと、その内容で編集を再開できます。 読み込んだ内容はこのブラウザに保存されます（今の編集内容は上書きされます）。

このブラウザの保存内容

編集内容はこのブラウザに自動保存されています。別の端末やブラウザには引き継がれないため、移すときはJSONファイルを書き出して読み込んでください。
