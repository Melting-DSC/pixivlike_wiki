export / import

書き出し

編集した記事をファイルとして保存します。JSONは再編集用、HTML・PNG・PDFは配布や閲覧用です。

書き出し形式

JSON

サイト・記事を1つのファイルにまとめます。あとから読み込んで編集を再開できます。

HTML

CSSと画像を埋め込んだ単体のHTMLです。そのまま配布したり、静的ホスティングに置いたりできます。

PNG

記事全体を1枚の画像として保存します。SNSや資料への貼り付けに向いています。

PDF

記事全体をA4サイズの複数ページに分割して保存します。印刷や配布用です。

書き出し中はボタンが一時的に使えなくなります。画像が多い記事は少し時間がかかります。

ファイルから読み込む

このサイトが書き出したJSON、または site / article の2ファイルを選択できます。 読み込んだ内容はこのブラウザに保存されます。

保存データ

編集内容はこのブラウザの localStorage に自動保存されています。別の端末やブラウザには引き継がれません。
